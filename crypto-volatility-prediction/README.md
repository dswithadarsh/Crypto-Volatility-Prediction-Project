# Cryptocurrency Volatility Prediction

This is a ready-to-submit project template for the assignment: *Cryptocurrency Volatility Prediction*.

Contents:
- `data/raw/sample_crypto.csv` - small synthetic sample dataset for demo.
- `notebooks/01_full_pipeline.ipynb` - runnable notebook demonstrating the pipeline on sample data.
- `src/` - modular scripts (data_loader.py, preprocessing.py, features.py, models.py, utils.py).
- `app/streamlit_app.py` - minimal Streamlit demo.
- `reports/` - EDA, HLD, LLD, Final Report templates.
- `diagrams/` - placeholder pipeline diagram.
- `requirements.txt` - Python dependencies.

**How to use**
1. Place your real dataset CSV at `data/raw/crypto.csv` (or update paths).
2. Install dependencies: `pip install -r requirements.txt`
3. Run the notebook (`notebooks/01_full_pipeline.ipynb`) or use scripts in `src/`.
